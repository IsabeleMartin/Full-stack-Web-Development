# 🚀 Ciclo de Projetos Fullstack — Do Básico ao Avançado

Este repositório reúne **4 projetos completos de desenvolvimento web fullstack**, organizados do **mais simples ao mais avançado**, com o objetivo de proporcionar uma formação prática, progressiva e sólida para quem deseja dominar backend, frontend, bancos de dados, autenticação, real-time e arquitetura moderna de software.

Cada projeto introduz novos conceitos, aumentando o nível de complexidade e ampliando sua experiência no mundo real de desenvolvimento.

---

## 🎯 Objetivo Geral

Construir uma trilha prática que permita:

* Desenvolver habilidades de **backend, frontend e banco de dados** de forma integrada.
* Entender como estruturar um projeto real do zero ao deploy.
* Criar um portfólio completo com projetos reais e apresentáveis.
* Evoluir de CRUD básico até aplicações com **autenticação avançada e comunicação em tempo real**.

Ao final, você terá passado por todas as etapas importantes de um dev fullstack moderno.

---

# 🧱 Projetos

---

## 🟦 **1. CRUD de Tarefas (To-Do App) — Nível: Básico**

### ✔ Objetivo

Aprender os fundamentos do fullstack: API REST, CRUD, frontend consumindo backend, rotas simples e operações básicas de banco.

### 🔍 O que será visto

* Criação de API REST com Node/Express ou FastAPI
* CRUD completo (Create, Read, Update, Delete)
* Integração frontend ↔ backend
* Formulários e validação simples
* SQLite/PostgreSQL + ORM (Prisma ou SQLAlchemy)
* Estruturação inicial de um projeto fullstack
* Testes básicos com Postman/Insomnia

---

## 🟩 **2. Sistema de Usuários + Autenticação — Nível: Intermediário**

### ✔ Objetivo

Introduzir autenticação, autorização e fluxo de login — fundamentais para qualquer aplicação moderna.

### 🔍 O que será visto

* Cadastro, login e logout
* Hash de senhas com bcrypt/argon2
* JWT ou cookies de sessão
* Middleware de rotas protegidas
* CRUD de posts/blog com associação ao usuário
* Controle de permissões (um usuário só edita seus dados)
* Proteção de páginas no front (Next.js)

---

## 🟧 **3. Mini E-commerce com Carrinho — Nível: Intermediário/Avançado**

### ✔ Objetivo

Trabalhar lógica real de mercado: estoque, carrinho, pedidos e relacionamento entre tabelas.

### 🔍 O que será visto

* Modelagem completa: Products, Orders, OrderItems
* Carrinho de compras dinâmico
* Atualização de estoque
* Checkout “fake” com finalização de pedido
* Painel simples de admin (CRUD de produtos)
* Upload de imagens (opcional)
* Filtros, busca, paginação
* Tratamento de erros e validações complexas

---

## 🟪 **4. Dashboard em Tempo Real (IoT / Chat / Monitoramento) — Nível: Avançado**

### ✔ Objetivo

Dominar comunicação em tempo real e lidar com dados ao vivo — habilidade valorizada em sistemas de IoT, chats e dashboards.

### 🔍 O que será visto

* WebSockets / Socket.IO
* Notificações em tempo real
* Gráficos dinâmicos com dados atualizando na tela
* API REST + canal realtime
* Simulador de sensores (ou outra fonte de dados)
* Paginação e histórico via banco de dados
* Autenticação + permissões avançadas
* Arquitetura de serviços (frontend, backend e worker simulador)
